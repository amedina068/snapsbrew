# Get help with Snapsbrew

One person maintains Snapsbrew. Answers to questions, issues and pull requests are not immediate. Use the correct place for each request, so that the maintainer can find it.

## Read the documentation

The documentation is at [snapsbrew.com/docs](https://snapsbrew.com/docs). It has the install guides, the configuration, the REST API reference, the MCP server and a [troubleshooting page](https://snapsbrew.com/docs/self-hosting/troubleshooting).

## Ask a question

Ask a question in the [Q&A category of the Discussions](https://github.com/amedina068/snapsbrew/discussions/categories/q-a). Do not open an issue for a question.

Put these items in your question:

- The version: the release tag, the image tag or the commit.
- The install method: the Docker image, Docker Compose from source, or a local install.
- What you tried and what occurred.

Remove tokens, passwords, emails and signed URLs before you paste a log.

## Report a bug or ask for a feature

Open an [issue](https://github.com/amedina068/snapsbrew/issues/new/choose) with the bug report form or the feature request form. To discuss an idea before a feature request, use the [Ideas category](https://github.com/amedina068/snapsbrew/discussions/categories/ideas) of the Discussions.

## Report a security problem

Do not open a public issue or a discussion for a security problem. Read [SECURITY.md](SECURITY.md) and report the problem in private.
